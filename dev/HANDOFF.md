## 소스 구조 (중요)
- `beta/index.html`은 **생성 파일**. 직접 고치지 말고 `dev/v5/`의 모듈을 고친 뒤 빌드.

  (patch.py의 SRC/DST/V는 /home/claude/habit-quest, /home/claude/v5 기준. 중간 파일은 임시 폴더에 씀)

  - 순서: `patch.py` → `patch2` → … **번호순**(`ls dev/v5/patch*.py | sort -V`), 지금 마지막은 patch100(v13.19 w144)·patch99(v13.18 — 베타 띠만, 코드는 v5z.js 직접)·patch98(v13.17 w143)·patch97(v13.16 w142)·patch96(v13.15 w141)·옛 patch95(v13.14 — 베타 띠만, 코드는 w110·w131·w72를 직접 고침) → 다음은 patch101(w145.js·v145.css). **patch 파일은 `patch.py` 끝에 `exec(open(V+'patchNN.py'...))` 줄을 직접 더해야 돌아감**. 새 모듈은 `dev/v5/wNNN.js`(+`vNNN.css`)로 만들고 patch 파일이 끼워 넣음. 어느 버전이 어느 patch·w 파일인지는 CHANGELOG 칸 제목. 직전 patch 파일 하나를 베껴 시작.
  - **v6.9부터 `route();boot();`는 스크립트 맨 끝**. patch22~36은 w70~w84를 그 바로 앞에 넣음 → 다음 모듈도 `\nroute();boot();\n` 앞에. 첫 render 때 모든 모듈·감싸기가 준비돼 있음.
  - 함수 덮어쓰기: function 선언은 **뒤에 있는 게 이김**. 이미 대입된 함수는 `{const _f=f;f=function(){...}}`로 감쌈. 어떤 함수를 누가 감쌌는지는 CHANGELOG에서 이름으로 찾기.

## 핵심 설계
- **점수는 행동 카드에만.** XP=성장(레벨) · 골드=현실의 돈·자원 · 컨디션=지금의 몸과 마음. 해당 없으면 0. 카드 없는 할 일은 크기·중요도 점수(C.taskXP), 골드는 경제 영역이거나 t.px일 때만(v7.1).
- **행동 카드** = 무엇을 하면 몇 점 · **할 일** = 언제 할지(한 번/반복) · **습관** = 카드 + 그 카드에 이어진 반복 할 일(↻) · **일퀘** = 반복 할 일의 ☑(그 일이 뜨는 날만).
- **루틴** = 머리 할 일(t.rid) + 단계 = 묶인 할 일(t.parent, t.rstep). r.steps는 순서표. 점수는 단계 = 할 일 점수, 루틴 = 완주 보너스만. 단계 할 일은 늘 status 0, '오늘 함' = t.last.
- **용기**: 카드 a.brave / 할 일 t.brave·t.bsz71. 보스 전투에서 ⚔️ 용기 XP = 치명타.
- **도파민 메뉴('🍬 지금 어때?')** = 카드의 a.dopa(코스) + 상태(DSTATE).
- **HP(컨디션)** = 하루 시작값(+ v10.3부터 어제 몸 끝값 30% 이월) + **🔋 컨디션 영역**의 컨디션 변화 합(몸 몫은 그날 몸 최대까지 — 어젯밤 잠·술·야식, v10.3)(영역 평균 아님, v10.2부터 — 📈 진척·💰 경제 영역은 HP와 따로, ⚔ 용기 기록은 늘 넣음). 지난 날(v10.2 전)은 아침 기준값 + 모든 변화. 영역 막대는 균형 보기용. 영역 레벨은 따로(aNeed67).
