## 핵심 설계
- **점수는 행동 카드에만.** XP=성장(레벨) · 골드=현실의 돈·자원 · 컨디션=지금의 몸과 마음. 해당 없으면 0. 카드 없는 할 일은 크기·중요도 점수(C.taskXP), 골드는 경제 영역이거나 t.px일 때만(v7.1).
- **행동 카드** = 무엇을 하면 몇 점 · **할 일** = 언제 할지(한 번/반복) · **습관** = 카드 + 그 카드에 이어진 반복 할 일(↻) · **일퀘** = 반복 할 일의 ☑(그 일이 뜨는 날만).
- **루틴** = 머리 할 일(t.rid) + 단계 = 묶인 할 일(t.parent, t.rstep). r.steps는 순서표. 점수는 단계 = 할 일 점수, 루틴 = 완주 보너스만. 단계 할 일은 늘 status 0, '오늘 함' = t.last.
- **용기**: 카드 a.brave / 할 일 t.brave·t.bsz71. 보스 전투에서 ⚔️ 용기 XP = 치명타.
- **도파민 메뉴('🍬 지금 어때?')** = 카드의 a.dopa(코스) + 상태(DSTATE).
- **HP(컨디션)** = 아침 기준값 + 모든 컨디션 변화의 합(영역 평균 아님). 영역 막대는 균형 보기용. 영역 레벨은 따로(aNeed67).
- 유지되는 것: 세부 옵션별 점수, 나쁜 행동 누적 배수(C.penalty), 흐름 끊기 보너스(C.chain), 방치 경보.
